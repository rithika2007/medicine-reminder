# 💊 Medicine Reminder

A Python desktop application that helps users remember to take their medicines at scheduled times.

## 🚀 Features

- Add medicine name and reminder time
- Store medicine details using SQLite
- Schedule daily reminders
- Desktop notifications
- Simple graphical user interface using Tkinter

## 🛠️ Technologies Used

- Python
- Tkinter
- SQLite
- Schedule
- Plyer

## 📸 How It Works

1. Enter the medicine name.
2. Enter the reminder time in `HH:MM` format.
3. Click **Add Medicine**.
4. The medicine is stored in the SQLite database.
5. At the scheduled time, a desktop notification reminds the user.
